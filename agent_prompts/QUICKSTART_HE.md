# 🚀 התחלה מהירה - מחולל Blueprints

## 3 צעדים פשוטים:

### 1️⃣ העתק את הפרומפט
פתח את הקובץ: **`blueprint_generator_agent.md`**

לחץ Ctrl+A (בחר הכל) → Ctrl+C (העתק)

### 2️⃣ הדבק ב-ChatGPT
1. פתח https://chatgpt.com (צריך GPT-4!)
2. התחל שיחה חדשה
3. Ctrl+V (הדבק)
4. Enter

### 3️⃣ בקש Blueprint
כתוב מה אתה רוצה, למשל:

```
צור תרחיש שכאשר מישהו ממלא טופס ב-Google Forms,
שולח לי מייל עם הפרטים
```

ChatGPT יחזיר לך JSON מלא - פשוט תעתיק וייבא ל-Make.com!

---

## 📋 איך לייבא ל-Make.com?

1. העתק את כל ה-JSON שהסוכן יצר
2. היכנס ל-Make.com
3. Scenarios → ⚙️ → Import Blueprint
4. הדבק את ה-JSON
5. **חשוב!** קשר את החשבונות שלך (Google Forms, Gmail וכו')
6. Save → Run 🎉
