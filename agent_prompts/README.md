## 🧪 דוגמה חיה

**אתה כותב:**
```
צור תרחיש:
- כשמגיע webhook עם נתונים
- שלח אותם ל-API חיצוני
- אם יש שגיאה, נסה שוב 3 פעמים
- ואז עדכן גיליון עם התוצאה
```

**הסוכן מחזיר:**
```json
{
  "name": "Webhook to API with Retry",
  "flow": [
    {
      "id": 1,
      "module": "http:webhookEvent",
      ...
    },
    {
      "id": 2,
      "module": "http:MakeARequest",
      "onerror": [...retry logic...],
      ...
    },
    {
      "id": 3,
      "module": "google-sheets:addRow",
      ...
    }
  ],
  "metadata": {...}
}
```

**+ הסבר מה כל module עושה!**
