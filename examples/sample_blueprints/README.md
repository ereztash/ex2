# Sample Blueprints

This directory contains sample blueprints generated by MakeGPT for testing and demonstration.

## Usage

Generate a blueprint and save it here:

```bash
python -m src.main "Your automation idea" --output examples/sample_blueprints/my_scenario.json
```

## Testing

1. Generate a blueprint
2. Validate it: The system validates automatically, but you can also use:
   ```bash
   python -m pytest tests/test_validator.py
   ```
3. Test Base64 encoding:
   ```bash
   python -c "from src.encoder import Base64Encoder; import json; \
      bp = json.load(open('examples/sample_blueprints/my_scenario.json')); \
      print(Base64Encoder.encode(bp))"
   ```

## Importing to Make.com

To import a generated blueprint to Make.com:

1. Open the JSON file
2. Copy the entire content
3. Go to Make.com → Scenarios → Create New Scenario
4. Click the "..." menu → Import Blueprint
5. Paste the JSON
6. **Important**: Link all connections manually (HIL requirement)

Alternatively, use the CLI deploy feature:
```bash
python -m src.main "Your idea" --deploy --team-id YOUR_TEAM_ID --folder-id YOUR_FOLDER_ID
```
