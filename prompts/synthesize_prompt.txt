=== MAKE.COM BLUEPRINT SCHEMA 2.1 (MANDATORY) ===

ROOT STRUCTURE (REQUIRED):
{
  "name": "string",
  "flow": [...],
  "metadata": {
    "version": 1,
    "scenario": {
      "roundtrips": 1,
      "maxErrors": 3,
      "autoCommit": false,
      "sequential": false,
      "confidential": false,
      "dataloss": false,
      "dlq": false
    }
  }
}

MODULE STRUCTURE (each in flow array):
{
  "id": integer (required, unique),
  "module": "app:action" (required),
  "version": 1 (required),
  "parameters": {
    "__IMTCONN__": integer (for authenticated apps),
    "__IMTHOOK__": integer (for webhooks),
    ...module-specific params
  },
  "mapper": {
    "field": "{{sourceModuleId.sourceField}}"
  },
  "metadata": {
    "designer": {
      "x": integer (required),
      "y": integer (required)
    },
    "restore": {},
    "expect": []
  },
  "filter": {
    "name": "string",
    "conditions": [[
      {"a": "{{1.field}}", "b": "value", "o": "operator"}
    ]]
  }
}

ROUTER MODULE STRUCTURE:
{
  "id": integer,
  "module": "builtin:BasicRouter",
  "version": 1,
  "routes": [
    {
      "flow": [
        ...modules for this route
      ],
      "filter": {
        "name": "Route name",
        "conditions": [[...]]
      }
    }
  ],
  "metadata": {"designer": {"x": int, "y": int}}
}

=== MANDATORY RULES ===

1. EVERY module MUST have:
   - id (unique integer)
   - module (string)
   - version (integer, usually 1)
   - metadata.designer (object with x, y)

2. ROOT MUST have:
   - name (string)
   - flow (array, non-empty)
   - metadata.scenario (object with ALL required fields)

3. CONNECTIONS:
   - Use __IMTCONN__ placeholders (e.g., "__IMTCONN__": 123456)
   - Use random 6-digit numbers for placeholder IDs
   - User will link these manually (HIL requirement)

4. WEBHOOKS:
   - Use __IMTHOOK__ placeholders
   - Same format as connections

5. DATA MAPPING:
   - Syntax: {{moduleId.fieldName}}
   - Example: {{1.email}}, {{2.data}}
   - Arrays: {{1.items[]}}
   - Nested: {{1.user.name}}

6. FILTER CONDITIONS:
   - Array of arrays: [[{a, b, o}]]
   - Operators: "text:equal", "text:notequal", "text:contains",
     "number:equal", "number:greater", "exists", "notexists"
   - Example: {"a": "{{1.status}}", "b": "urgent", "o": "text:equal"}

7. POSITIONING:
   - Start at x: 0, y: 0
   - Increment x by 150 for each module
   - Router branches: adjust y

8. metadata.scenario:
   - roundtrips: 1 (default)
   - maxErrors: 3 (default)
   - autoCommit: false (default)
   - sequential: false (true for critical operations)
   - Other booleans: false
